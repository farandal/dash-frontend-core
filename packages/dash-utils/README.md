# @dashadmin/dash-utils

> Utility and helper functions for the Dash framework.

## Overview

General-purpose helpers (formatting, data massaging, guards) reused across packages.

## Key exports & features

- Formatting & data helpers
- Depends only on `dash-constants`

## Installation

```bash
# From the public npm registry
npm install @dashadmin/dash-utils

# Or the local Verdaccio registry (unscoped)
npm install dash-utils --registry http://localhost:4873
```

## Internal Dash dependencies

`@dashadmin/dash-constants`
