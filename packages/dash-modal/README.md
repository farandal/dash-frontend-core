# @dashadmin/dash-modal

> Modal components for Dash.

## Overview

Reusable modal primitives built on top of `dash-styles`, `dash-dialog` and `dash-auto-admin`.

## Key exports & features

- Composable modal components
- Integrates with dialog & auto-admin forms

## Installation

```bash
# From the public npm registry
npm install @dashadmin/dash-modal

# Or the local Verdaccio registry (unscoped)
npm install dash-modal --registry http://localhost:4873
```

## Internal Dash dependencies

`@dashadmin/dash-styles`, `@dashadmin/dash-auto-admin`, `@dashadmin/dash-dialog`
